# 主界面与交互重设计（方案调研）

> 目标：减少驾驶场景下的点击/扫视成本，让"是否在录像、怎么开始/停止、文件在哪"在一眼内完成；
> 设置项按使用频率分层，低频/调试项收进二级页面。本文是设计提案，不含代码改动。
> 线框图见 [mockups.html](mockups.html)（`mockups.png` 为静态截图）。

## 0. 调研依据

- Android for Cars：任务尽可能短、点按次数尽量少；内容要一眼可读，驾驶时文字 1–3 行、≤120 字符；
  驾驶员应能在约 2 秒内读完并回到路面；输入响应 <0.25 秒。
  [设计原则](https://developer.android.com/design/ui/cars/guides/foundations/design-principles) ·
  [互动原则](https://developers.google.com/cars/design/design-foundations/interaction-principles)
- BlackVue 新版 App 的首页把最常用功能放在最前，强调 status / recordings / settings 的快速入口。
  [BlackVue App Update](https://www.blackvue.com.sg/news/discover-the-new-blackvue-app-update-a-smarter-sleeker-and-more-user-friendly-experience)
- Viofo App 的主路径也是"实时画面 + 文件 + 设置"，设置不占据主画面。
  [Viofo A229 手册](https://www.manualslib.com/manual/4511250/Viofo-A229-Ultra.html?page=16)

## 1. 现状审计

### 1.1 首页

- 3 张等权工具卡（记录仪/拼接/压缩）；记录仪是每天用的主功能，却没有状态、没有"开始录像"。
- 从冷启动到开始录像：**2 次点击 + 页面切换**；只想确认"是否在录"也要走同样路径。
- 拼接/压缩是低频管理动作，和记录仪抢同样的视觉权重。

### 1.2 记录仪页

- 底部 5 个等权按钮：开始/停止、预览、设置、黑屏、录像文件。主操作不突出，且"设置"与"停止录像"同样大。
- 状态是顶部 4–6 行等宽文本（录像/分辨率/剩余空间/GPS/曝光/温度），需要逐行读，不符合"1–3 行、2 秒扫视"。
- 预览开关、黑屏是"每次可能用"的操作，但塞在底部主栏；文件是停车后才用。
- 停止录像是一击即停，驾驶中误触代价高。

### 1.3 设置

- 一个长滚动列表里 **25 个控件**：分辨率、帧率、码率、单段、配额、摄像头、行车模式、曝光模式、快门、ISO、EV、对焦、视野、自动镜头、高光、AE CSV、EV 包围、锐化、水印、倒装、水印辅助、地点、退出、能力查看、电池白名单……
- 日常项（分辨率/帧率/单段）与调试项（AE CSV/EV 包围/能力查看）混在一起；易误改、难找、也难解释。
- 曝光/道路名等新功能继续加入，列表只会更长。

## 2. 设计原则

1. **录像状态是产品主状态**：首页/记录页/通知统一显示 REC、时长、存储。
2. **一屏一个主操作**：开始/停止是唯一主按钮；停止用长按 1.5 秒防误触。
3. **驾驶时只留 3 件事**：状态、开始/停止、退出驾驶模式；管理动作（文件/设置/工具）降到次级。
4. **停下车再做管理**：文件、拼接、压缩、高级设置不占据驾驶视图。
5. **渐进披露**：设置分"常用 / 存储 / 画面 / 高级 / 调试"，调试项默认折叠甚至长按版本号才显示。
6. **一眼可读**：状态用 2 行内的 chip/图标；避免等宽长段落；主按钮 ≥64dp 高。
7. **少一步**：首页可一键开始/停止；可选"启动自动录像"接近零点击。

## 3. 三个主界面方案

### 方案 A：首页即记录仪控制台（推荐，改动最小）

- 首页顶部变成记录仪状态卡：`● 录像中 00:12:34` + `1080P·30fps` + `剩余 18GB` + `GPS`；
- 卡片内一个大按钮"开始录像/停止录像"，旁边"查看画面"；
- 下方才是"工具"：四视角拼接、视频压缩（较弱视觉权重）；
- 设置齿轮放在卡片右上角。
- 冷启动到开始录像：**1 次点击**；确认状态：**0 次点击**（首页直接显示）。

适合：每天打开 App 才开始录、或想保留工具入口的用户。

### 方案 B：极简驾驶页 + 设置抽屉（推荐与 A 组合）

- 点记录仪后直接进入全屏驾驶页：只保留画面、顶部一条半透明状态、底部一个大按钮；
- 5 秒无操作自动隐藏按钮，点屏幕唤出；
- 底部次级只留 2–3 个小图标：录像文件、黑屏、更多；
- "更多"打开分组设置（拍摄/存储/画面/高级），调试项折叠；
- 停止录像长按 1.5 秒；黑屏由"录像中 10 秒无操作自动进入"替代手动按钮，长按退出。

适合：手机固定在中控/挡风玻璃，驾驶中几乎不操作。

### 方案 C：自动记录 + 管理页（零点击）

- 打开 App / 上车通电自动开始录像；
- 首页变成管理页：顶部"记录中"横幅 + 停止按钮；下面是最近片段、拼接、压缩、设置；
- 通知保留"停止录像"；可加桌面快捷方式/快捷设置磁贴；
- 自动录像必须在设置里显式开启，并提供低电量/高温/存储不足的自动停止规则。

适合：希望"装好就不用管"的用户；风险是隐私/耗电/热，需要明确开关与提示。

### 方案 D：底部双 Tab（仅未来工具多时考虑）

- "记录 | 工具"两个 Tab；记录 Tab = B 的驾驶页，工具 Tab = 拼接/压缩/设置。
- 优点：扩展性好；缺点：驾驶时多一个选择维度，不建议作为默认首屏。

## 4. 推荐组合

**A + B + 可选 C**：

- 首页用 A：状态卡 + 一键开始/停止 + 工具降级；
- 进入记录仪后用 B：极简驾驶页、自动隐藏、长按停止、自动黑屏；
- 设置里提供"启动时自动开始录像"（默认关），开启后接近 C；
- 拼接/压缩移到"工具"区，驾驶时不可见。

## 5. 操作去留清单

| 操作 | 建议位置 | 理由 |
|---|---|---|
| 开始/停止录像 | 首页卡片 + 驾驶页主按钮 | 唯一高频主操作 |
| 录像状态/时长/存储/GPS | 首页卡片 + 驾驶页顶部 | 一眼确认 |
| 录像文件 | 驾驶页小图标 + 首页"更多" | 停车后使用 |
| 黑屏/息屏 | 自动（录像中无操作 10s） | 减少驾驶中点击 |
| 预览开关 | 设置 > 画面 | 固定偏好，不是每趟都改 |
| 设置入口 | 首页齿轮 + 驾驶页"更多" | 低频 |
| 分辨率/帧率/码率/单段 | 设置 > 拍摄 | 一次配置 |
| 摄像头/视野/自动镜头 | 设置 > 拍摄 | 安装时配置 |
| 曝光模式 | 设置 > 拍摄（可加"车牌优先"快捷开关） | 低频但需可发现 |
| 快门/ISO/EV/对焦/高光 | 设置 > 高级曝光（折叠） | 调参项 |
| 水印/地点/锐化/倒装 | 设置 > 画面 | 一次配置 |
| 存储配额/清理 | 设置 > 存储 | 低频 |
| AE CSV/EV 包围/能力查看/电池白名单 | 设置 > 调试（长按版本号） | 诊断/路测 |

## 6. 设置信息架构（建议）

```
设置
├─ 拍摄：分辨率、帧率、码率、单段时长、摄像头、视野/变焦、曝光模式
├─ 存储：配额、剩余空间、清理、录像目录
├─ 画面：预览、水印、地点、快门/ISO 小字、锐化、倒装
├─ 高级曝光（折叠）：快门上限、ISO 上限、EV、对焦、高光优先
└─ 调试（长按版本号）：AE CSV、EV 包围、相机能力、电池白名单、4K 测试
```

原则：一级设置不超过 5 组、每组不超过 7 项；调试项默认不可见；修改后提示"重新开始录像生效"。

## 7. 状态呈现建议

- 用 2 行内 chip：`● 录像中 00:12:34` / `1080P·30 · 剩余 18GB · GPS 31km/h`；
- 曝光/ISO/亮度只放在"更多"或设置里，不占主状态；
- 颜色 + 文案双编码（不要只靠红/绿）；
- 错误（存储不足/过热/相机重连）用一条高对比提示，点击进设置。

## 8. 验收指标

- 冷启动→开始录像 ≤1 次点击；记录中→停止 ≤1 次长按；
- 首页状态扫视 ≤2 秒；驾驶页首屏按钮 ≤5 个；
- 设置一级分组 ≤5，常用项查找 ≤2 次点击；
- 无误触停止（长按确认）、无驾驶中误入高级设置；
- 屏幕熄灭/黑屏不中断录像。
